# Как поселить бота на Railway

Понадобится минут 15 и два бесплатных аккаунта: GitHub и Railway.
Карта для старта не нужна.

---

## Шаг 1. Положить файлы на GitHub

Railway берёт код из репозитория, поэтому сначала GitHub.

1. Зарегистрируйся на [github.com](https://github.com).
2. Справа сверху **+** → **New repository**.
3. Название: `vika-bot`, тип **Private**. Нажми **Create repository**.
4. На странице репозитория нажми **uploading an existing file** и перетащи туда все файлы из папки:
   `bot.py`, `compliments.py`, `requirements.txt`, `railway.json`, `Procfile`, `README.md`.
5. Внизу нажми **Commit changes**.

## Шаг 2. Создать проект на Railway

1. Зайди на [railway.com](https://railway.com) → **Login with GitHub**.
2. **New Project** → **Deploy from GitHub repo**.
3. Разреши Railway доступ к репозиторию `vika-bot` и выбери его.
4. Railway сам увидит Python и начнёт сборку. Ждать пару минут.

Команду запуска указывать не нужно — она уже прописана в `railway.json`.

## Шаг 3. Вписать токен

1. Открой свой сервис → вкладка **Variables** → **New Variable**.
2. Добавь две штуки:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | твой токен от @BotFather |
| `STATE_FILE` | `/data/state.json` |

3. Нажми **Deploy** (или кнопку с изменениями сверху), чтобы применилось.

Когда в логах (вкладка **Deployments** → **View Logs**) появится «Бот запущен» — всё
работает. Открывай бота в Телеграме и жми `/start`.

## Шаг 4. Постоянная память (по желанию, 1 минута)

Без этого шага при каждом перезапуске бот забудет, какие комплименты уже отправлял,
и список пойдёт по новой. Чтобы память жила:

1. В сервисе нажми правой кнопкой на пустом месте → **Add Volume**
   (или **Settings** → **Volumes** → **Add Volume**).
2. Mount path впиши: `/data`
3. Сохрани — сервис перезапустится сам.

Переменную `STATE_FILE` мы уже указали на этот путь, так что больше ничего не нужно.

## Про деньги — честно

У Railway нет вечного бесплатного тарифа в чистом виде, но есть два уровня:

- **Trial** — при регистрации дают $5 разово на 30 дней, карта не нужна.
- **Free** — после этого аккаунт переходит на бесплатный план: $1 кредита
  в месяц, один проект, 0.5 ГБ памяти. Наш бот почти всё время просто спит
  и ест мало, так что в этот доллар он с большой вероятностью укладывается.
  Но гарантии нет: если месяц выйдет чуть дороже, Railway остановит сервис
  и предложит тариф **Hobby** за $5 в месяц.

Расход видно в реальном времени в разделе **Usage** — загляни туда через недельку
после запуска, сразу поймёшь, укладываешься или нет.

## Полезное

- **Часовой пояс.** В `bot.py` есть строка `TZ_OFFSET_HOURS = 5` — это Ташкент.
  Комплимент дня придёт в 09:00 по-нашему.
- **Поменять комплименты.** Правишь `compliments.py` прямо на GitHub (карандашик) →
  **Commit changes** → Railway сам пересоберёт бота за пару минут.
- **Если бот молчит** — смотри логи: Deployments → View Logs. Там будет видно ошибку.
- **Токен** держи только в переменной `BOT_TOKEN`, в самом коде оставь заглушку —
  тогда он не утечёт вместе с репозиторием.
