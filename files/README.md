# Бот с комплиментами для Виктории 💛

Три файла:
- `bot.py` — сам бот
- `compliments.py` — 500 комплиментов и 58 ласковых обращений
- `requirements.txt` — что нужно установить

---

## Шаг 1. Сделать бота в Телеграме

1. Открой в Телеграме **@BotFather**
2. Напиши `/newbot`
3. Придумай имя (например «Комплименты для Вики») и логин (должен заканчиваться на `bot`, например `vika_love_bot`)
4. BotFather пришлёт **токен** — длинную строку вида `7712345678:AAH-xxxxxxxxxxxxxxxxx`. Скопируй её.

## Шаг 2. Вставить токен

Открой `bot.py` в любом текстовом редакторе, найди в начале строку:

```python
TOKEN = os.environ.get("BOT_TOKEN", "СЮДА_ВСТАВЬ_ТОКЕН")
```

и вместо `СЮДА_ВСТАВЬ_ТОКЕН` вставь свой токен (кавычки оставь).

## Шаг 3. Запустить

Нужен установленный Python (python.org, версия 3.9 и выше).
Открой терминал в папке с файлами и выполни две команды:

```bash
pip install pyTelegramBotAPI
python bot.py
```

Если появилась надпись «Бот запущен» — всё работает. Открывай бота в Телеграме,
жми `/start` и отправляй ссылку Вике.

**Важно:** пока это окно терминала открыто — бот живой. Закроешь — бот замолчит.

## Что умеет бот

| Действие | Что происходит |
|---|---|
| Кнопка «💛 Комплимент» или любое сообщение | случайный комплимент |
| `/daily` или кнопка «☀️ Комплимент дня» | включает/выключает автоматический комплимент каждое утро |
| `/reset` | обнуляет историю, комплименты начинают идти по новой |
| `/help` | подсказка |

Повторов нет: пока все 500 не закончатся, ни один не придёт дважды.
Ласковое обращение подставляется случайно из 58 вариантов, поэтому
комбинаций получается несколько тысяч.

Время утренней рассылки меняется в `bot.py` в строке `DAILY_TIME = "09:00"`
(это время сервера, на котором запущен бот).

## Как добавить свои комплименты

Открой `compliments.py`, в конце списка `COMPLIMENTS` допиши строчку:

```python
    "{n}, ты сегодня особенно прекрасна.",
```

`{n}` — место, куда подставится ласковое имя. Можно и без него.
Обращения добавляются так же — в список `NAMES` в начале файла.

## Чтобы бот работал всегда (не только при включённом компьютере)

Проще всего залить папку на бесплатный хостинг для ботов — например
**Railway**, **Render** или **PythonAnywhere**. Схема везде одинаковая:
загружаешь файлы, указываешь команду запуска `python bot.py` и токен
в переменной окружения `BOT_TOKEN`. Если возьмёшься — скажи, распишу
пошагово под конкретный сервис.
